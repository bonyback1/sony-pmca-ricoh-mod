# A6300 连接手机 App 指南

## 结论（先看这个）

索尼当前最新的手机 App 是 **Creators' App**（2023 年起取代 Imaging Edge Mobile），但 **A6300 不在 Creators' App 的支持列表内**。索尼官方明确说明：不兼容的机型请继续使用 **Imaging Edge Mobile**（以下简称 IEM）。

来源：索尼官方支持页 CCCA03001（含 A6300 专属页面 `sony.com/electronics/support/e-mount-body-ilce-6000-series/ilce-6300l/articles/CCCA03001`）。

所以对 A6300 而言，"能用的最新索尼 App" = **Imaging Edge Mobile**。无法通过任何软件手段让 Creators' App 识别 A6300——这是相机固件/协议层面的限制，不是设置问题。

---

## A6300 的连接硬件

| 项目 | 情况 |
|---|---|
| WiFi | 802.11b/g/n（仅 2.4GHz） |
| NFC | 有（一键配对，**仅 Android**） |
| 蓝牙 | **没有** → 后台自动传图、常连、云端上传等都用不了 |
| 预装相机 App | Smart Remote Embedded（智能遥控），IEM 通过它连接 |

> 因为没有蓝牙，所有需要"常连"或"后台传图"的现代功能（无论 IEM 还是 Creators' App）在 A6300 上都做不到——这是硬件限制。

---

## 第一步：在手机上装 App

- iOS：App Store 搜 **Imaging Edge Mobile**
- Android：Google Play 搜 **Imaging Edge Mobile**

**不要装 Creators' App**，它识别不了 A6300。

---

## 第二步：连接（二选一）

### 方法 A：NFC 一键配对（仅 Android 带 NFC）

1. A6300 开机 → `Menu` → 顶部 **Application（应用列表）** 图标 → 选 **Smart Remote Embedded** → 启动
2. 手机解锁屏幕，用手机背部 NFC 区贴相机右侧握把处的 **N 标志**
3. 手机自动弹出 IEM 并完成配对，相机显示"已连接"
4. IEM 里出现实时取景 → 可遥控

### 方法 B：二维码 / 直连 WiFi（iOS 必用，Android 也行）

1. A6300 → `Menu` → 顶部 **Application** 图标 → **Smart Remote Embedded** → 启动
   - 屏幕显示 SSID（形如 `DIRECT-xxxx:ILCE-6300`）和密码
   - 密码就是相机的"设备密码"，在 `Menu → 网络 → 设备密码` 里设置/查看
   - 部分固件会显示二维码
2. 手机：系统设置 → WiFi → 选中上面的 SSID → 输入密码连接
3. 手机打开 IEM → 自动检测到相机 → 配对（首次可能需相机端确认）

---

## 第三步：传图（不想遥控，只想把照片传到手机）

1. A6300 回放模式 → 选中一张照片 → `Menu` → **发送到智能手机**
2. 选择"在本机上选择影像"或"此影像/多个影像"
3. 相机建立直连 WiFi → 手机连接后 IEM 自动接收
4. **关键限制：A6300 不能直接传 RAW 到手机。**
   - 若选中 RAW 发送，相机会自动转成一张 JPEG 传给你（非原始 RAW）
   - 想要原始 RAW：必须用读卡器或 USB 连电脑

---

## 连接后能做什么

- 实时取景遥控快门（照片 + 视频）
- 调整部分设置：曝光补偿、驱动模式、白平衡（有限）、对焦点、变焦（部分镜头）
- 把 JPEG 传到手机
- 用手机 GPS 给照片打位置标签（"位置信息链接"，需拍摄时保持连接）

## 做不到的（别折腾，硬件墙）

- 后台自动传图 / 常连（需蓝牙，A6300 没有）
- 云端自动备份（Creators' App 专属 + 需新机型）
- 传 RAW 到手机（只能读卡器）
- 动物眼部对焦、AI 主体识别等新功能（需新机型硬件）

---

## 固件确认

A6300 最终固件版本是 **v3.00**（含人类眼部对焦、代理 4K 录制）。已装 OpenMemories → 大概率已是 v3.00。可在 `Menu → 设置（扳手图标）→ 版本` 确认。

---

## 排错速查

| 现象 | 处理 |
|---|---|
| IEM 检测不到相机 | 确认手机连的是相机的 DIRECT-xxxx WiFi，不是家里 WiFi |
| 配对失败 | `Menu → 网络 → 复位网络设置`，重新来一次 |
| 传图很慢 | 正常，A6300 WiFi 仅 2.4GHz；传大文件建议改读卡器 |
| 想后台自动备份 | 做不到，A6300 无蓝牙；考虑换 A6400 及以后机型 |
